<h3 align="center">Shopvento</h3>

<p align="center">
  One system for bookable events, vouchers, shop and goods.<br>

</p>

---

Shopvento runs tastings, courses, workshops, leisure experiences such as lasertag or escape rooms, restaurants and retail shops from one back office: seat bookings and appointments, single and multi-purpose vouchers, an online shop with delivery and DHL labels, POS connection, B2B ordering, finance and DATEV export, WhatsApp and Google Business. Every function is also reachable through MCP, so AI assistants can work with it.

**React components.** We are preparing `@shopvento/ui`, the React components behind our own storefronts: event and seat booking, vouchers, cart and checkout, customer account. They talk to the Shopvento API and can be themed and embedded into any website. The package and its source will be published here.

Shopvento is made by [digital cuisine GmbH & Co. KG](https://cuisine.digital), Hannover.
